# [Spectral Distribution Alignment for Enhanced Generalization in Regression](https://link.springer.com/chapter/10.1007/978-3-032-06106-5_16)

This project has been accepted by ECMLPKDD 2025

The src is built from [C-Mixup](https://github.com/huaxiuyao/C-Mixup)

## dataset
[RCF-MNIST](https://drive.google.com/drive/folders/1pTRT7fA-hq6p1F7ZX5oJ0tg_I1RRG6OW?usp=sharing) and [DTI](https://drive.google.com/drive/folders/1pTRT7fA-hq6p1F7ZX5oJ0tg_I1RRG6OW?usp=sharing) are released by C-Mixup 

MPI3D and dSprites can be acquired from [DARE-GRAM](https://github.com/ismailnejjar/DARE-GRAM?tab=readme-ov-file#data-links). The data lists for these two datasets are provided in [Google Drive](https://drive.google.com/drive/folders/17kpR1qQ0BYiUo16p39vCd1NcHGLDdgdT?usp=drive_link). Please put the lists in the correspoding folder before running the code. 

BiwiKinect can be acquired from [Kaggle](https://www.kaggle.com/datasets/kmader/biwi-kinect-head-pose-database)
## Run

We provide ```main.sh``` file in each folder.
