# Spectral Distribution Alignment for Enhanced Generalization in Regression

This project has been accepted by ECMLPKDD 2025

The src is built from [C-Mixup](https://github.com/huaxiuyao/C-Mixup)

## dataset
[RCF-MNIST](https://drive.google.com/drive/folders/1pTRT7fA-hq6p1F7ZX5oJ0tg_I1RRG6OW?usp=sharing) and [DTI](https://drive.google.com/drive/folders/1pTRT7fA-hq6p1F7ZX5oJ0tg_I1RRG6OW?usp=sharing) are released by C-Mixup 

MPI3D and dSprites can be acquired from [DARE-GRAM](https://github.com/ismailnejjar/DARE-GRAM?tab=readme-ov-file#data-links)

BiwiKinect can be acquired from [Kaggle](https://www.kaggle.com/datasets/kmader/biwi-kinect-head-pose-database)
## Run

We provide ```main.sh``` file in each folder.
